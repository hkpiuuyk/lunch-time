# 런치타임 (Lunch Time)

급식 줄의 예상 대기 시간을 보여 주는 Node.js 웹 프로젝트입니다.

## 실행 방법

```powershell
cd lunch-time
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 열면 됩니다.

## 현재 구현 기능

- 급식실 3곳의 대기 인원, 혼잡도, 예상 대기 시간
- 급식실을 누르면 내 급식실로 선택
- `+ 1명`, `- 1명` 버튼으로 인원 변동 시연
- 알림 켜기 버튼과 안내 메시지

실제 서비스로 발전시킬 때에는 카메라·QR 출입·학생 입력 데이터를 이용해 대기 인원을 자동으로 받으면 됩니다.
